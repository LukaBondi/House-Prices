# House Prices — Prototype Baseline (SYS-304, Milestone 1)

## Problem
Predict a home's sale price (`SalePrice`) from its structural, quality, and
location features — a supervised **tabular regression** problem.

## Dataset
[Kaggle: House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
(Ames, Iowa housing data — 1,460 training rows, ~79 explanatory features).

> **Note on the data in this repo:** `data/train.csv` here is a **synthetic
> stand-in** generated by `data/generate_synthetic_data.py`, built to match the
> real dataset's column names, types, missingness patterns, and rough value
> ranges. This lets the pipeline run end-to-end without a Kaggle download.
> To use the real competition data, download `train.csv` from the link above,
> drop it into `data/`, and re-run the notebook — no code changes required.

## Why this domain
Tabular regression is a well-scoped, well-understood problem with a clean
numeric target and a mix of numeric/categorical features, making it a good
surface for exercising the full pipeline (EDA → preprocessing → baseline
model → evaluation → serialization) before adding system complexity in later
milestones.

## Approach
1. **EDA** — distribution of `SalePrice`, missing-value audit, correlation
   analysis, and scatter/box plots of the strongest predictors
   (`OverallQual`, `GrLivArea`, `YearBuilt`, `TotalBsmtSF`).
2. **Preprocessing** — median imputation for numeric columns, most-frequent
   imputation + one-hot encoding for categorical columns, wired together with
   `sklearn.compose.ColumnTransformer` inside a `Pipeline`.
3. **Baseline model** — `XGBRegressor` with light, untuned hyperparameters
   (300 trees, max depth 4). No hyperparameter search at this stage — the
   goal is a working proof-of-concept, not SOTA accuracy.
4. **Evaluation** — MAE, RMSE, R², and RMSLE (the actual Kaggle leaderboard
   metric) on a held-out 20% split, plus a predicted-vs-actual plot and
   feature importances.
5. **Serialization** — the full pipeline (preprocessing + model) is saved to
   `models/baseline_xgb_pipeline.pkl` via `joblib`, then reloaded to confirm
   inference works from disk alone.

## Baseline results (on the synthetic stand-in data)
| Metric | Value |
|---|---|
| MAE   | ~$17,300 |
| RMSE  | ~$21,600 |
| R²    | ~0.88 |
| RMSLE | ~0.133 |

These numbers will shift once run against the real Kaggle data, but they
confirm the pipeline is sound and the model is learning real signal.

## Reproducing
```bash
pip install pandas numpy scikit-learn xgboost matplotlib seaborn joblib jupyter
jupyter notebook house_prices_prototype.ipynb
```
To skip retraining (e.g. for the demo recording), run every cell except the
"Train Baseline Model" cell — Section 8 loads `models/baseline_xgb_pipeline.pkl`
directly and runs inference on held-out samples.
